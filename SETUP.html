Setup TPB(P) Pertanian

  1. Buka config.js dengan Notepad.
  2. Isi SUPABASE_URL dengan Project URL.
  3. Isi SUPABASE_ANON_KEY dengan Publishable Key.
  4. Simpan config.js.
  5. Buka index.html.

Penting: Jangan masukkan Secret Key atau service_role key.

Portal versi ini tidak memerlukan Python atau Node.js untuk ujian asas.
